🗡️ Copy-this cookbook · Team 6738

Exactly what to type to add a mechanism, a subsystem, and its state machine.

No theory. Every recipe is: make these files → paste this → change these numbers → call these functions. That's it.

iHow to use this

  1. Find your recipe below in "Which recipe?".
  2. Create the files it names. Two files per subsystem: Thing.java and ThingConstants.java, inside src/main/java/frc/robot/subsystems/thing/.
  3. Copy the code blocks verbatim. Use the Copy button.
  4. Change only the numbers in the "fill in" table. Nothing else.
  5. Call the functions in the "functions" table from your commands / RobotContainer.
  6. Run ./gradlew simulateJava "-Dorg.gradle.java.home=C:/Users/Public/wpilib/2026/jdk" and watch it in AdvantageScope.
🚫 Non-negotiables

1) Work on a branch, never main. 2) Every mechanism needs a simModel. 3) Your subsystem's periodic() MUST call each mechanism's (and the state machine's) periodic() — miss this and nothing moves.

1Arm / pivot / hood

Anything that rotates to a target angle. Archetype: PositionalMechanism.

  1. Create subsystems/arm/ArmConstants.java and paste:
    ArmConstants.java
    package frc.robot.subsystems.arm;

import com.ctre.phoenix6.signals.GravityTypeValue;
import frc.excalib2.control.*;

public class ArmConstants {
    public static final int    MOTOR_ID          = 20;
    public static final double ROTOR_TO_MECHANISM = 60.0;   // rotor turns per arm turn
    public static final Gains  REAL_GAINS = new Gains(50, 0, 0.8)
                                    .withGravity(0.3, GravityTypeValue.Arm_Cosine);
    public static final Gains  SIM_GAINS  = new Gains(40, 0, 0);
    public static final MotionConstraints MOTION = new MotionConstraints(3.0, 5.0); // Expo kV,kA
    public static final CurrentBudget BUDGET = new CurrentBudget(40, 30);           // stator, supply
    public static final double MIN_RAD = 0.0, MAX_RAD = 1.57;   // soft limits
}
  2. Create subsystems/arm/Arm.java and paste:
    Arm.java
    package frc.robot.subsystems.arm;

import edu.wpi.first.math.system.plant.DCMotor;
import edu.wpi.first.units.measure.Angle;
import edu.wpi.first.wpilibj2.command.Command;
import edu.wpi.first.wpilibj2.command.SubsystemBase;
import edu.wpi.first.wpilibj2.command.button.Trigger;
import frc.excalib2.control.ControlMode;
import frc.excalib2.device.CANDeviceId;
import frc.excalib2.mechanisms.MechanismConfig;
import frc.excalib2.mechanisms.PositionalMechanism;

import java.util.function.Supplier;
import static edu.wpi.first.units.Units.Radians;
import static frc.robot.subsystems.arm.ArmConstants.*;

public class Arm extends SubsystemBase {

    private final PositionalMechanism arm = new PositionalMechanism(
        new MechanismConfig("Arm", new CANDeviceId(MOTOR_ID))
            .controlMode(ControlMode.VOLTAGE)                       // FOC later, after SysId
            .rotorToMechanismRatio(ROTOR_TO_MECHANISM)
            .gains(REAL_GAINS, SIM_GAINS)
            .motion(MOTION)
            .softLimits(Radians.of(MIN_RAD), Radians.of(MAX_RAD))
            .tolerance(Radians.of(0.02))
            .currentBudget(BUDGET)
            .simArmModel(DCMotor.getKrakenX60Foc(1), ROTOR_TO_MECHANISM, 0.05, 0.3, MIN_RAD, MAX_RAD, MIN_RAD));

    // ---- the functions you call from outside ----
    public Command goTo(Supplier<Angle> target) { return run(() -> arm.setGoal(target.get())); }
    public Command goTo(double radians)          { return run(() -> arm.setGoalRotations(radians / (2*Math.PI))); }
    public Trigger atGoal() { return arm.atGoal; }

    @Override public void periodic() { arm.periodic(); }   // REQUIRED
}
  3. Fill in only these:
    ConstantSet it to
    MOTOR_IDYour TalonFX CAN id.
    ROTOR_TO_MECHANISMTotal gear reduction: motor rotations for one arm rotation.
    MIN_RAD / MAX_RADTravel limits in radians (0 = your chosen zero).
    gainsLeave the starters; replace after a SysId run.

Functions you use

FunctionDoes
MOVEarm.setGoal(Angle)Command a profiled move to an angle.
READarm.atGoalTrigger, true when within tolerance.
READarm.getPosition()Current angle.
LOOParm.periodic()Call inside the subsystem's periodic(). Mandatory.
💡 Has an absolute encoder?

Replace .rotorToMechanismRatio(ROTOR_TO_MECHANISM) with .fusedCANcoder(new CANDeviceId(ENC_ID), rotorToSensor, sensorToMech, Rotations.of(offset)). Everything else stays the same.

2Turret

Same as R1, but it wraps to the nearest legal angle instead of unwinding. Add two lines to the R1 config.

Turret.java — config differences vs R1
private final PositionalMechanism turret = new PositionalMechanism(
    new MechanismConfig("Turret", new CANDeviceId(MOTOR_ID))
        .controlMode(ControlMode.VOLTAGE)
        .rotorToMechanismRatio(ROTOR_TO_MECHANISM)
        .gains(REAL_GAINS, SIM_GAINS)
        .motion(MOTION)
        .softLimits(Radians.of(-5.4), Radians.of(1.5))   // <-- the full rotation range
        .continuousWrap()                                 // <-- ADD THIS: shortest legal path
        .tolerance(Radians.of(0.04))
        .currentBudget(new CurrentBudget(120, 80))
        .simRotationalModel(DCMotor.getKrakenX60Foc(1), 0.5, ROTOR_TO_MECHANISM));

public Command aimAt(Supplier<Angle> target) { return run(() -> turret.setGoal(target.get())); }
⚠️ Two required lines

.softLimits(...) AND .continuousWrap() — wrap only works with limits set. Functions are identical to R1 (setGoal, atGoal, periodic).

3Elevator / slide

Moves to a length in meters. Archetype: LinearExtension. Same shape as R1 but with the *Meters helpers.

  1. Paste Elevator.java:
    Elevator.java
    package frc.robot.subsystems.elevator;

import com.ctre.phoenix6.signals.GravityTypeValue;
import edu.wpi.first.math.system.plant.DCMotor;
import edu.wpi.first.units.measure.Distance;
import edu.wpi.first.wpilibj2.command.Command;
import edu.wpi.first.wpilibj2.command.SubsystemBase;
import edu.wpi.first.wpilibj2.command.button.Trigger;
import frc.excalib2.control.*;
import frc.excalib2.device.CANDeviceId;
import frc.excalib2.mechanisms.LinearExtension;
import frc.excalib2.mechanisms.MechanismConfig;

import static edu.wpi.first.units.Units.Meters;

public class Elevator extends SubsystemBase {
    private static final int    MOTOR_ID        = 50;
    private static final double ROTOR_PER_METER = 25.0;   // rotor turns to raise 1 metre

    private final LinearExtension lift = new LinearExtension(
        new MechanismConfig("Elevator", new CANDeviceId(MOTOR_ID))
            .controlMode(ControlMode.VOLTAGE)
            .rotorToMechanismRatio(ROTOR_PER_METER)
            .gains(new Gains(30, 0, 0, 0, 12, 0).withGravity(0.4, GravityTypeValue.Elevator_Static),
                   new Gains(30, 0, 0))
            .motion(new MotionConstraints(2.0, 4.0))       // m/s, m/s²
            .softLimitsMeters(Meters.of(0.0), Meters.of(1.2))
            .toleranceMeters(Meters.of(0.01))
            .currentBudget(new CurrentBudget(60, 40))
            .simElevatorModel(DCMotor.getKrakenX60Foc(2), ROTOR_PER_METER, 5.0, 0.02, 0.0, 1.2, 0.0));

    public Command goTo(Distance height) { return run(() -> lift.setLength(height)); }
    public Trigger atGoal() { return lift.atGoal; }

    @Override public void periodic() { lift.periodic(); }   // REQUIRED
}
FunctionDoes
MOVElift.setLength(Distance)Move to a height (e.g. Meters.of(0.8)).
READlift.atGoal · lift.getLength()Arrived? / current height.
LOOPlift.periodic()Mandatory.
💡 Slide mounted on a moving arm?

Use the other constructor: new LinearExtension(config, () -> armAngleRadians, kG) and set the gains' kG to 0. It applies kG·sin(armAngle) automatically.

4Flywheel / drum

Holds a target speed in rotations-per-second. Archetype: VelocityMechanism.

Flywheel.java
package frc.robot.subsystems.flywheel;

import edu.wpi.first.math.system.plant.DCMotor;
import edu.wpi.first.wpilibj2.command.Command;
import edu.wpi.first.wpilibj2.command.SubsystemBase;
import edu.wpi.first.wpilibj2.command.button.Trigger;
import frc.excalib2.control.*;
import frc.excalib2.device.CANDeviceId;
import frc.excalib2.mechanisms.MechanismConfig;
import frc.excalib2.mechanisms.VelocityMechanism;

import static edu.wpi.first.units.Units.Rotations;

public class Flywheel extends SubsystemBase {
    private static final int LEADER_ID = 31, FOLLOWER_ID = 32;

    private final VelocityMechanism wheel = new VelocityMechanism(
        new MechanismConfig("Flywheel", new CANDeviceId(LEADER_ID))
            .follower(new CANDeviceId(FOLLOWER_ID), false)         // 2nd motor, same shaft
            .controlMode(ControlMode.VOLTAGE)
            .rotorToMechanismRatio(1.2)
            .gains(new Gains(0.2, 0, 0, 0.33, 0.156, 0), new Gains(0.05, 0, 0, 0, 0.11, 0))
            .currentBudget(new CurrentBudget(120, 80))
            .tolerance(Rotations.of(2))                            // "at speed" window (rot/s)
            .simRotationalModel(DCMotor.getKrakenX60Foc(2), 0.01, 1.2));

    public Command spinAt(double rps) { return run(() -> wheel.setVelocityRotationsPerSecond(rps)); }
    public Command stop()             { return runOnce(wheel::stop); }
    public Trigger atSpeed()          { return wheel.atSpeed; }

    @Override public void periodic() { wheel.periodic(); }   // REQUIRED
}
FunctionDoes
SETwheel.setVelocityRotationsPerSecond(rps)Command a speed.
STOPwheel.stop()Neutral + clears the setpoint.
READwheel.atSpeedTrigger, true when up to speed.
LOOPwheel.periodic()Mandatory.

Open-loop spin + detect when a game piece stalls it. Archetype: RollerMechanism.

import edu.wpi.first.math.system.plant.DCMotor;
import edu.wpi.first.wpilibj2.command.Command;
import edu.wpi.first.wpilibj2.command.SubsystemBase;
import edu.wpi.first.wpilibj2.command.button.Trigger;
import frc.excalib2.control.ControlMode;

import frc.excalib2.mechanisms.MechanismConfig;
import frc.excalib2.mechanisms.RollerMechanism;

public class Roller extends SubsystemBase {
    private static final int MOTOR_ID = 13;

    private final RollerMechanism roller = new RollerMechanism(
        new MechanismConfig("Roller", new CANDeviceId(MOTOR_ID))
            .controlMode(ControlMode.VOLTAGE)
            .currentBudget(new CurrentBudget(80, 30))
            .simRotationalModel(DCMotor.getKrakenX60Foc(1), 0.002, 3.0));

LOOProller.periodic()Mandatory.

6Add a state machine to a subsystem

When a subsystem has named modes (CLOSED / OPEN / PUMP), use a StateMachine instead of if-statements.

  1. Define the enum (inside or next to the subsystem):
    IntakeState.java
    public enum IntakeState { CLOSED, OPEN, PUMP }
  2. Build the machine as a field. Chain the calls in this exact order: actions, then transitions.
    inside Intake.java
    import frc.excalib2.statemachine.StateMachine;
import static frc.robot.subsystems.intake.IntakeState.*;

private final StateMachine<IntakeState> machine =
    new StateMachine<>("Intake", CLOSED)                          // name, starting state
        // ---- what happens in each state ----
        .onEnter(CLOSED, () -> fourBar.setGoal(CLOSED_ANGLE))
        .onEnter(OPEN,   () -> fourBar.setGoal(OPEN_ANGLE))
        .whileIn(PUMP,   pumpCommand())                            // a Command, runs while in PUMP
        .onExit(PUMP,    roller::stop)
        // ---- which moves are legal ----
        .transition(CLOSED, OPEN)                                  // CLOSED -> OPEN allowed
        .transition(OPEN,   PUMP)                                  // OPEN   -> PUMP allowed
        .transitionFromAny(CLOSED);                                // anyone -> CLOSED (escape)
  3. Tick it every loop in the subsystem's periodic():
    Intake.periodic()
    @Override public void periodic() {
    fourBar.periodic();
    roller.periodic();
    machine.periodic();        // REQUIRED — ticks the machine
}
  4. Expose a way to request states:
    Intake.java methods
    public Command setState(IntakeState s) { return machine.requestCommand(s); }
public void requestState(IntakeState s) { machine.request(s); }   // for the superstructure
public Trigger inState(IntakeState s)  { return machine.in(s); }

The exact state-machine functions

Build (in the field)Meaning
new StateMachine<>(name, startState)Create it.
.onEnter(state, Runnable)Run once when entering the state.
.onExit(state, Runnable)Run once when leaving.
.whileIn(state, Command)Schedule a command on entry, cancel on exit.
.transition(from, to)Allow this move.
.transition(from, to, guard)Allow only when the BooleanSupplier guard is true (else it waits).
.transitionFromAny(to)Allow from every state.
Use (elsewhere)Meaning
machine.requestCommand(state)A Command that requests the state.
machine.request(state)Request it right now (returns true if it happened).
machine.in(state)Trigger, true while in that state.
machine.getCurrentState()The current enum value.
machine.periodic()Tick — call every loop.
⚠️ Default-deny

If you don't .transition(...) a move, it's illegal and the request quietly fails (and logs). List every move you want.

7A full subsystem (two mechanisms + a state machine)

The complete pattern: an intake with a four-bar (position) + a roller, driven by a state machine. This is the whole file — copy it and rename.

subsystems/intake/Intake.java (complete)
package frc.robot.subsystems.intake;

import com.ctre.phoenix6.signals.GravityTypeValue;
import edu.wpi.first.math.system.plant.DCMotor;
import edu.wpi.first.wpilibj2.command.Command;
import edu.wpi.first.wpilibj2.command.Commands;
import edu.wpi.first.wpilibj2.command.SubsystemBase;
import edu.wpi.first.wpilibj2.command.button.Trigger;
import frc.excalib2.control.*;
import frc.excalib2.device.CANDeviceId;
import frc.excalib2.mechanisms.*;
import frc.excalib2.statemachine.StateMachine;

import static edu.wpi.first.units.Units.Radians;
import static frc.robot.subsystems.intake.Intake.State.*;

public class Intake extends SubsystemBase {
    public enum State { CLOSED, OPEN, PUMP }

    private static final double OPEN_RAD = 0.0, CLOSED_RAD = 2.0, GEARING = 14.14;

    // 1) mechanisms
    private final PositionalMechanism fourBar = new PositionalMechanism(
        new MechanismConfig("Intake/FourBar", new CANDeviceId(10))
            .follower(new CANDeviceId(34), true)
            .controlMode(ControlMode.VOLTAGE)
            .rotorToMechanismRatio(GEARING)
            .gains(new Gains(30, 0, 0).withGravity(0.8, GravityTypeValue.Arm_Cosine), new Gains(30, 0, 0))
            .motion(new MotionConstraints(1.5, 2.0, 0))
            .softLimits(Radians.of(0), Radians.of(2.4))
            .tolerance(Radians.of(0.02))
            .currentBudget(new CurrentBudget(80, 60))
            .simArmModel(DCMotor.getKrakenX60Foc(2), GEARING, 0.3, 0.3, 0, 2.4, CLOSED_RAD));

    private final RollerMechanism roller = new RollerMechanism(
        new MechanismConfig("Intake/Roller", new CANDeviceId(13))
            .controlMode(ControlMode.VOLTAGE)
            .currentBudget(new CurrentBudget(80, 30))
            .simRotationalModel(DCMotor.getKrakenX60Foc(1), 0.002, 3.0));

    // 2) state machine
    private final StateMachine<State> machine = new StateMachine<>("Intake", CLOSED)
        .onEnter(CLOSED, () -> { fourBar.setGoal(Radians.of(CLOSED_RAD)); roller.stop(); })
        .onEnter(OPEN,   () -> { fourBar.setGoal(Radians.of(OPEN_RAD));  roller.runDutyCycle(0.8); })
        .whileIn(PUMP,   pumpCommand())
        .transitionFromAny(CLOSED)
        .transitionFromAny(OPEN)
        .transitionFromAny(PUMP);

    // 3) pump = oscillate the four-bar while the roller feeds
    private Command pumpCommand() {
        return Commands.repeatingSequence(
            run(() -> { fourBar.setGoal(Radians.of(1.6)); roller.runDutyCycle(0.8); }).withTimeout(0.5),
            run(() -> { fourBar.setGoal(Radians.of(0.0)); roller.runDutyCycle(0.8); }).withTimeout(0.5));
    }

    // 4) public API
    public Command setState(State s)  { return machine.requestCommand(s); }
    public void requestState(State s) { machine.request(s); }
    public Trigger hasPiece()         { return roller.currentSpike(40, 0.2); }

    // 5) THE REQUIRED LOOP
    @Override public void periodic() {
        fourBar.periodic();
        roller.periodic();
        machine.periodic();
    }
}
✅ That's a complete, sim-ready subsystem

Numbered 1–5: mechanisms → state machine → helper command → public API → the required periodic. Every subsystem you write is this shape.

8Add it to the superstructure

The superstructure turns one robot goal into a state for every subsystem. Do this after your subsystems exist.

  1. Add a goal row to the RobotState enum — one column per subsystem:
    superstructure/RobotState.java
    public enum RobotState {
    //           intake            shooter               transport
    IDLE      (Intake.State.CLOSED, Shooter.State.IDLE,     Transport.State.IDLE),
    AIM_HUB   (Intake.State.CLOSED, Shooter.State.LOOK_HUB, Transport.State.IDLE),
    SHOOT_HUB (Intake.State.PUMP,   Shooter.State.SHOOT_HUB,Transport.State.FEED);

    public final Intake.State intake; public final Shooter.State shooter; public final Transport.State transport;
    RobotState(Intake.State i, Shooter.State s, Transport.State t){ intake=i; shooter=s; transport=t; }
}
  2. Fan the goal out — one loop builds the whole machine:
    superstructure/Superstructure.java
    StateMachine<RobotState> machine = new StateMachine<>("Superstructure", RobotState.IDLE);
for (RobotState goal : RobotState.values()) {
    machine.onEnter(goal, () -> {
        intake.requestState(goal.intake);
        shooter.requestState(goal.shooter);
        transport.requestState(goal.transport);
    });
    machine.transitionFromAny(goal);
}
  3. Request a goal from anywhere:
    usage
    superstructure.request(RobotState.SHOOT_HUB);        // returns a Command
  4. (Optional) interlock — make FEED wait for the shooter with a guard on that subsystem's edge:
    in Transport's machine
    .transition(Transport.State.IDLE, Transport.State.FEED, shooter.ready())

9Swerve (drivetrain)

The swerve constants already live in SwerveConfig.java. You only construct it and set the drive command.

  1. Construct it in RobotContainer:
    RobotContainer.java
    public final SwerveSubsystem swerve = new SwerveSubsystem(
    SwerveConfig.DRIVETRAIN,
    SwerveConfig.FRONT_LEFT, SwerveConfig.FRONT_RIGHT,
    SwerveConfig.BACK_LEFT,  SwerveConfig.BACK_RIGHT);
  2. Set the teleop drive as its default command:
    in RobotContainer constructor
    swerve.setDefaultCommand(swerve.fieldCentricDriveCommand(
    () -> -controller.getLeftY(),   // forward
    () -> -controller.getLeftX(),   // left
    () -> -controller.getRightX(),  // rotate
    SwerveConfig.MAX_SPEED_MPS, SwerveConfig.MAX_OMEGA_RAD_PER_SEC, 0.1));
  3. Wire vision + auto (once, in the constructor):
    in RobotContainer constructor
    swerve.withLimelight("limelight-turret",
        () -> swerve.getHeading().plus(TurretOffsetGetter.instance.getTurretOffset()),
        TurretOffsetGetter.instance::isFast)
     .withVisionPoseTransform(SwerveConfig::turretPoseToRobotPose);
swerve.configureAutoBuilder(SwerveConfig.PP_TRANSLATION_GAINS, SwerveConfig.PP_ROTATION_GAINS);

🚫 Register before you build the chooser

An unregistered name in a .auto silently becomes a no-op — the robot drives but never acts. Every name in every auto must have a registerCommand.
